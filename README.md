# Investment Calculator
A Python application that models long-term investment growth using compound interest. The program calculates portfolio growth based on user inputs, displays year-by-year investment data and summary statistics, exports the results to a CSV file, and visualizes investment growth using Matplotlib.

# Features
- Calculates compound investment growth
- Supports user's choice of initial investment, monthly contributions, interest rate, inflation rate, compounding frequency, and investment length.
- Displays interest earned and ending balance for each year.
- Calculates inflation-adjusted final balance and the percentage split between principal and interest over the investment's term.
- Exports investment data to a CSV file for Excel analysis and generates a portfolio growth visualization using Matplotlib.

# Technologies
- Python
- CSV
- Matplotlib

# Installation
1. Install Python 3.
2. Install Matplotlib:
   pip install matplotlib

# Running the Program
Run the following command in terminal:
    python investment_calculator.py
If the above doesn't work, try:
    python3 investment_calculator.py
